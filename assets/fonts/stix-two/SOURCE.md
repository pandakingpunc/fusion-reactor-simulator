# STIX Two fonts

- Source: https://github.com/stipub/stixfonts, tag `v2.13b171`, files `fonts/static_ttf/*.ttf`
- Licence: SIL Open Font License 1.1 (`OFL.txt`); Reserved Font Names apply, so derived
  (subset) fonts embedded in generated PDFs keep the original name only as permitted by the OFL
  for embedded, non-modified-for-distribution use inside documents.
- Used by the publication plot engine (`src/plot`) to embed subset TrueType fonts in PDF output
  and to measure text widths consistently in SVG and PDF.
