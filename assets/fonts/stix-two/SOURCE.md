# STIX Two fonts

- Source: https://github.com/stipub/stixfonts, tag `v2.13b171`, files `fonts/static_ttf/*.ttf`
- Licence: SIL Open Font License 1.1 (`OFL.txt`). The fonts are redistributed unmodified.
  Subsets embedded in generated PDF figures are part of those documents, which the OFL does
  not restrict (see the OFL FAQ on embedding fonts in documents).
- Used by the publication plot engine (`src/plot`) to embed subset TrueType fonts in PDF output
  and to measure text widths consistently in SVG and PDF.
